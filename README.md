# Spelling Bee — Vocabulary Practice

Immersion Grade 5 First Semester 單字聽力拼字練習，包含 Part 1-4（100 字）與 Week 1-18（971 字），共 1022 個真人發音音檔。

## 功能
- 依 Part / Week / 分類篩選測驗範圍
- 播放速度切換（0.5× / 0.7× / 1.0×）
- 鍵盤操作：Enter 送出答案、N 下一題
- 中文提示、顯示答案、計分

## 使用
直接開啟 index.html 即可，無需伺服器。

線上版：GitHub Pages 連結（部署後補上）

## 音檔來源
Merriam-Webster 真人錄音
